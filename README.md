# MakeupGame Test Task

Тестовое задание на реализацию механики нанесения макияжа в Unity.

## Реализовано
- Нанесение крема
- Нанесение теней
- Нанесение румян
- Нанесение помады
- Очистка макияжа спонжем
- Управление рукой через drag
- Автоматические анимации взятия, нанесения и возврата инструмента
- Проверка попадания в зону лица

## Основная логика
Механика построена на state machine для управления состояниями руки и инструмента.

### Состояния
- `Idle` — ожидание действия игрока
- `PickingUp` — рука автоматически берет инструмент
- `Carrying` — инструмент у игрока, доступен drag
- `Applying` — проигрывается анимация нанесения
- `Returning` — инструмент автоматически возвращается на место

### Инструменты
- `Cream`
- `Eyeshadow`
- `Lipstick`
- `Blush`

## Основные технические моменты реализации

### 1. State Machine
Используется `MakeupStateMachine` для централизованного управления переходами между состояниями.
Это позволило:
- разделить автоматические действия и действия игрока
- избежать конфликтов между drag и анимацией
- упростить обработку завершения каждого этапа

### 2. Координация логики
Главная логика собрана в `MakeupCoordinator`.
Он:
- реагирует на нажатия по косметике
- запускает нужные анимации руки
- хранит выбранный макияж/цвет
- обрабатывает возврат инструмента
- завершает цикл действия

### 3. Анимация руки
Для анимации использован `DOTween`.
Рука:
- приходит из стартовой позиции
- берет инструмент
- для кисточки делает набор цвета в палитре
- переходит в позицию для drag
- после нанесения возвращает инструмент на место
- затем возвращается в исходную позицию

### 4. Drag и Face Zone
Во время состояния `Carrying` игрок может перетаскивать руку.
При отпускании:
- вне зоны лица действие не выполняется
- в зоне лица запускается нанесение макияжа

Проверка выполняется через `FaceZoneChecker`.

### 5. Работа с кисточкой и палитрой
Для теней и румян используется отдельная точка `BrushDipPoint`.
Это нужно для того, чтобы в палитру попадала именно кисточка, а не вся рука.
Также рассчитывается смещение от руки до кончика кисти, чтобы анимация выглядела корректно.

### 6. Возврат предметов
После завершения нанесения инструмент автоматически возвращается на исходное место.
Для этого сохраняются:
- скрытый предмет
- точка возврата
- последовательность возврата руки

### 7. Сброс макияжа
При нажатии на спонж макияж сбрасывается сразу, без анимации, согласно ТЗ.

## Использованные скрипты
- `MakeupStateMachine` — состояния и текущий инструмент
- `MakeupCoordinator` — основная логика механики
- `HandAnimator` — автоматические анимации руки
- `HandDragHandler` — drag-управление рукой
- `HandToolVisual` — отображение инструмента в руке
- `MakeupApplier` — применение результата макияжа на персонажа
- `FaceZoneChecker` — проверка попадания в зону лица
- `UIColorButton`, `CreamButton`, `LipstickButton` — обработка UI-ввода
